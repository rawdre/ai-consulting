# Comeketo CRM Memory

This file is a compact reusable memory layer for future agents working the Comeketo CRM operation.

## Identity of the operation

This is not generic outreach.

This is an operator-grade CRM workflow built to:

- move leads
- avoid dropped context
- make follow-up reliable
- turn actual work into repeatable systems

## What the operator cares about most

- getting leads to respond
- getting them on the phone with André
- moving them toward tasting when it makes sense
- keeping the inbox clear without losing control
- never sending the wrong date, wrong language, or wrong tone

## Non-negotiable defaults

- customer-facing language:
  - `English`
- ownership source:
  - Close `LEAD OWNER = 01. 😎 Andre`
- `Won`:
  - do not send
- `Lost`:
  - do not send unless explicit override
- default move:
  - phone first
  - tasting second

## Tasting rules

Tasting dates are operator-fed.

At this point in the cycle:

- `Sunday, May 3, 2026 at 5:30 PM`
- `Sunday, May 17, 2026 at 2:00 PM`
- `Sunday, May 31, 2026 at 2:00 PM`

Do not:

- guess future dates
- use stale dates
- say just `Sunday`

Use explicit dates.

## Email rules

- HTML-first
- quote emails should look polished
- calculator button belongs in ballpark quotes
- if quote and tasting belong together, send one combined email
- avoid duplicate-touch behavior

## SMS rules

- only use SMS when the route is real and the plan calls for it
- if André asked for text-only, do not silently fall back to email

## Calendar rules for tastings

- calendar:
  - `Catering Tastings`
- color:
  - `red`

## Research before the next move

If there was an answered call over `5 minutes`:

- research that first
- use transcript if present
- otherwise use the best adjacent call note / thread evidence

## Why this matters

The operation already learned hard lessons:

- stale dates create embarrassment
- wrong-language outreach breaks trust
- draft-only systems are not enough
- quotes with invented numbers are worse than slower correct quotes
- repeated generic tasting pushes are weak
