Loop School: build a system that runs when you are not there

Every other track on this site teaches you to build things. This one teaches you to build the thing that runs the things — so work happens overnight and your job in the morning is to read it, rate it, and correct it.

Fifteen minutes per session. Each session ends with something that exists: a file, a schedule, a rating, a rule. If a session ends with only understanding, it failed.

Loop School: construa um sistema que roda quando você não está

Todas as outras trilhas deste site ensinam a construir coisas. Esta ensina a construir a coisa que roda as coisas — o trabalho acontece de madrugada e o seu trabalho de manhã é ler, avaliar e corrigir.

Quinze minutos por sessão. Cada sessão termina com algo que existe: um arquivo, um agendamento, uma nota, uma regra. Se a sessão terminar só com entendimento, ela falhou.

The honest starting point O ponto de partida honesto

On May 13 you deleted five lines from mission-control-refresh.yml — four cron schedules. Since that day nothing in your stack has started on its own.

Em 13 de maio você apagou cinco linhas do mission-control-refresh.yml — quatro agendamentos cron. Desde aquele dia, nada no seu sistema começa sozinho.

You do not have a capability problem. You have 67 agents, 59 skills, 0 hooks, 0 schedules. The library is enormous and the running system is zero.

Você não tem um problema de capacidade. Você tem 67 agentes, 59 skills, 0 hooks, 0 agendamentos. A biblioteca é enorme e o sistema rodando é zero.

This track closes exactly that gap. It adds no tools.

Esta trilha fecha exatamente essa lacuna. Ela não adiciona ferramentas.

The Four Primitives Os Quatro Primitivos

A self-running system is only four parts Um sistema autônomo tem só quatro partes

More agents is not the unlock. Multiple agents give you width — five readers covering five areas at once. They do not give you autonomy. Autonomy is these four, in this order.

Mais agentes não é a chave. Vários agentes dão largura — cinco leitores cobrindo cinco áreas ao mesmo tempo. Eles não dão autonomia. Autonomia é isto aqui, nesta ordem.

1Trigger

Something starts the work

Algo inicia o trabalho

A cron schedule, a hook, an incoming message. Without this, you are the event loop and nothing is automated.

Um cron, um hook, uma mensagem que chega. Sem isso, você é o event loop e nada é automático.

2State

A file the run reads and writes

Um arquivo que a execução lê e escreve

So run #7 knows what run #6 already did. Without state, every run starts from zero and repeats itself.

Para que a execução nº 7 saiba o que a nº 6 já fez. Sem estado, toda execução começa do zero e se repete.

3Gate

Where it stops and waits for you

Onde ele para e espera por você

The design center, not an afterthought. An autonomous loop with no gate does not fail politely — it fails at volume, at 3am, into your customers' inboxes.

O centro do projeto, não um detalhe final. Um loop sem gate não falha educadamente — ele falha em volume, às 3 da manhã, na caixa de entrada dos seus clientes.

4Signal

It pulls you in only when needed

Ele te chama só quando precisa

A push to your phone, a Slack card. If you have to remember to check it, it is not a loop — it is another chore.

Um push no celular, um card no Slack. Se você precisa lembrar de conferir, não é um loop — é mais uma tarefa.

Block 1 · Sessions 1-3 Bloco 1 · Sessões 1-3

See the machine — change nothing Enxergar a máquina — não mudar nada

You cannot automate what you cannot describe. These three sessions are read-only on purpose.

Você não automatiza o que não consegue descrever. Estas três sessões são só leitura, de propósito.

1
15 minRead-only

Read your own wreckage

Leia os seus próprios destroços

Do: Open commit 7be8c9e — "Disable mission control scheduled refresh". Read the diff. Then write, in your own words, one paragraph: what did the schedule do that made you turn it off?

Faça: Abra o commit 7be8c9e — "Disable mission control scheduled refresh". Leia o diff. Depois escreva, com suas palavras, um parágrafo: o que o agendamento fez que te levou a desligá-lo?

Done when: LOOP-LOG.md exists with that paragraph as its first entry.

Pronto quando: LOOP-LOG.md existir com esse parágrafo como primeira entrada.

Why this is first: you already tried autonomy once and retreated. If you do not name what went wrong, you will build the same thing again and retreat again.

Por que é a primeira: você já tentou autonomia uma vez e recuou. Se não nomear o que deu errado, vai construir a mesma coisa e recuar de novo.

2
15 minRead-only

Inventory the four primitives

Inventarie os quatro primitivos

Do: Take one system you already own — Mission Control is the obvious one. Write a four-row table: Trigger, State, Gate, Signal. Mark each one exists or missing, and name the file.

Faça: Pegue um sistema que você já tem — o Mission Control é o óbvio. Escreva uma tabela de quatro linhas: Trigger, Estado, Gate, Sinal. Marque cada um como existe ou falta, e diga o arquivo.

Done when: the table is in LOOP-LOG.md and every row names a real file path or says "missing".

Pronto quando: a tabela estiver no LOOP-LOG.md e cada linha citar um caminho real ou disser "falta".

What you will find: State exists (mission-control-data/latest.json). Trigger is deleted. That is the whole story of your stack.

O que você vai descobrir: o Estado existe (mission-control-data/latest.json). O Trigger foi apagado. É essa a história inteira do seu sistema.

3
15 minThe hard one

Define "done" so a computer can check it

Defina "pronto" de um jeito que o computador consiga verificar

Do: Take one fuzzy goal — "follow up with quiet leads well" — and rewrite it until a script could evaluate it. Not "a good follow-up". Something like: "every lead with no activity in 7+ days and status not Won/Lost appears exactly once in today's card, and none appear twice in the same week."

Faça: Pegue um objetivo vago — "fazer bom follow-up com leads parados" — e reescreva até um script conseguir avaliar. Não "um bom follow-up". Algo como: "todo lead sem atividade há 7+ dias e com status diferente de Ganho/Perdido aparece exatamente uma vez no card de hoje, e nenhum aparece duas vezes na mesma semana."

Done when: you can read your criteria out loud and say for any given run "passed" or "failed" without arguing with yourself.

Pronto quando: você conseguir ler seu critério em voz alta e dizer, para qualquer execução, "passou" ou "falhou" sem discutir consigo mesmo.

This is the session most people skip, and it is why their loops spin forever or drift. A loop with no checkable goal cannot tell success from motion.

É a sessão que quase todo mundo pula, e é por isso que os loops giram para sempre ou saem do rumo. Um loop sem objetivo verificável não distingue sucesso de movimento.

Block 2 · Sessions 4-6 Bloco 2 · Sessões 4-6

Make it run — still touching nobody Fazer rodar — ainda sem falar com ninguém

The system starts working without you. It still sends nothing to any human being.

O sistema começa a trabalhar sem você. Ele ainda não envia nada para nenhum ser humano.

4
15 minThe unlock

Put the trigger back — read-only

Devolva o trigger — só leitura

Do: Add a schedule: block back to mission-control-refresh.yml. One cron, not four. Confirm first that every step it runs only reads and writes the snapshot — no send step, no outbox, nothing that reaches a customer.

Faça: Devolva um bloco schedule: ao mission-control-refresh.yml. Um cron, não quatro. Confirme antes que todos os passos só leem e gravam o snapshot — sem envio, sem outbox, nada que chegue a um cliente.

Done when: the file has one cron line and you have said out loud which line would send something to a human. There should be none.

Pronto quando: o arquivo tiver uma linha de cron e você tiver dito em voz alta qual linha enviaria algo a um humano. Não deve haver nenhuma.

This is a three-line change and it flips your entire stack from manual to self-starting. That asymmetry is the lesson.

É uma mudança de três linhas e ela vira o seu sistema inteiro de manual para automático. Essa assimetria é a lição.

5
15 minEvidence

Watch one unattended run

Assista a uma execução sem você

Do: The next day, open the Actions tab and read the log of a run you did not start. Not the summary — the log. Find the moment it decided something.

Faça: No dia seguinte, abra a aba Actions e leia o log de uma execução que você não iniciou. Não o resumo — o log. Encontre o momento em que ele decidiu algo.

Done when: you can point at the exact line where the run made a choice, and say whether it was right.

Pronto quando: você conseguir apontar a linha exata em que a execução tomou uma decisão e dizer se estava certa.

The habit this builds is the highest-return study habit available to you: reading what the machine actually saw at the moment it went wrong, instead of guessing afterward.

O hábito que isso cria é o de maior retorno disponível para você: ler o que a máquina realmente viu no momento do erro, em vez de adivinhar depois.

6
15 minBuild

Make the run produce a job card

Faça a execução produzir um card de trabalho

Do: Have the run write one small file — job-card.json — with four fields: what it saw, what it would do, what it skipped and why, and how sure it is.

Faça: Faça a execução gravar um arquivo pequeno — job-card.json — com quatro campos: o que ela viu, o que ela faria, o que ela pulou e por quê, e o quanto está segura.

Done when: a card exists for a day you were not present, and the "skipped" field is not empty. A loop that never skips anything is not judging — it is just moving.

Pronto quando: existir um card de um dia em que você não estava, e o campo "pulou" não estiver vazio. Um loop que nunca pula nada não está julgando — está só se mexendo.

Block 3 · Sessions 7-9 Bloco 3 · Sessões 7-9

The job form — where you become the teacher O formulário de trabalho — onde você vira o professor

This is the part you asked for: you walk in, the work is already done, you read it and rate it. Your rating is not paperwork — it is the training signal that changes the rules.

Esta é a parte que você pediu: você chega, o trabalho já está feito, você lê e avalia. Sua nota não é burocracia — é o sinal de treino que muda as regras.

7
15 minBuild

Build the job form page

Construa a página do formulário

Do: One page that renders today's job-card.json and gives you three buttons and one text box. The three buttons are the whole rating scale: Right / Wrong / Dangerous. The box is one line: why.

Faça: Uma página que mostra o job-card.json de hoje e te dá três botões e uma caixa de texto. Os três botões são a escala inteira: Certo / Errado / Perigoso. A caixa é uma linha: por quê.

Three options, not five. A ten-point scale feels rigorous and produces nothing you can act on. "Dangerous" is its own button because it is the only rating that should change a rule the same day.

Três opções, não cinco. Uma escala de dez pontos parece rigorosa e não gera nada acionável. "Perigoso" é um botão separado porque é a única nota que deve mudar uma regra no mesmo dia.

8
15 minBuild

Stack seven days on one screen

Empilhe sete dias em uma tela

Do: Make the ratings persist and show the last seven in a row. One day of ratings tells you nothing. Seven days shows you a pattern — and patterns are the only thing worth changing a rule over.

Faça: Faça as notas persistirem e mostre as últimas sete lado a lado. Um dia de notas não diz nada. Sete dias mostram um padrão — e padrão é a única coisa que justifica mudar uma regra.

Done when: you can see seven ratings at once without scrolling or clicking.

Pronto quando: você vir sete notas ao mesmo tempo, sem rolar nem clicar.

9
15 minThe actual loop

Read the ratings, change exactly one rule

Leia as notas, mude exatamente uma regra

Do: Look at your seven ratings. Find the most common reason for "Wrong". Change one rule in the run so that reason cannot happen again. Log the change with the date.

Faça: Olhe suas sete notas. Ache o motivo mais comum de "Errado". Mude uma regra da execução para que esse motivo não possa acontecer de novo. Registre a mudança com a data.

One rule. Change three and you will not know which one helped. This is the session that makes the whole thing a loop instead of a dashboard — and you will repeat it every week from here on.

Uma regra. Mude três e você não vai saber qual ajudou. É esta sessão que transforma tudo em loop em vez de painel — e você vai repeti-la toda semana daqui em diante.

Block 4 · Sessions 10-12 Bloco 4 · Sessões 10-12

Earn autonomy — one action at a time Conquistar autonomia — uma ação por vez

Only now does anything get to act on its own, and only the smallest reversible thing.

Só agora alguma coisa age sozinha, e apenas a menor coisa reversível.

10
15 minSafety

Kill switch and phone signal

Botão de parada e sinal no celular

Do: Two things. One: a single file or flag that halts every loop, testable in under ten seconds. Two: the run pushes to your phone when — and only when — it needs you.

Faça: Duas coisas. Um: um único arquivo ou flag que para todos os loops, testável em menos de dez segundos. Dois: a execução manda push para o celular quando — e só quando — precisar de você.

Done when: you have actually flipped the kill switch once and watched a run stop.

Pronto quando: você tiver acionado o botão de parada uma vez e visto uma execução parar de verdade.

Build this before anything acts, not after. A kill switch you have never tested is a belief, not a control.

Construa isso antes de qualquer ação, não depois. Um botão de parada nunca testado é uma crença, não um controle.

11
15 minPromotion

Promote exactly one action

Promova exatamente uma ação

Do: Pick the smallest, most reversible action the loop has been drafting correctly for two weeks — an internal Slack post, a CRM status advance. Let it do that one thing unattended. Everything else stays gated.

Faça: Escolha a ação menor e mais reversível que o loop vem preparando corretamente há duas semanas — um post interno no Slack, um avanço de status no CRM. Deixe que ele faça só isso sozinho. Todo o resto continua com gate.

Not customer email. Not now, and maybe never without a human tap. The August over-send is the reason that line exists.

Não é e-mail para cliente. Não agora, e talvez nunca sem um toque humano. O envio em excesso de agosto é a razão dessa regra existir.

12
15 minYour policy

Write the promotion rule

Escreva a regra de promoção

Do: Write down what any future job must prove before it graduates from drafting to acting. Yours will look something like: 14 unattended runs, zero "Dangerous", fewer than two "Wrong", reversible in one click, kill switch tested this month.

Faça: Escreva o que qualquer tarefa futura precisa provar antes de passar de rascunho para ação. A sua vai ser algo como: 14 execuções sem supervisão, zero "Perigoso", menos de dois "Errado", reversível em um clique, botão de parada testado neste mês.

Done when: the rule is written and you have applied it to a second job without rethinking it from scratch. That reuse is the proof you learned the pattern and not just the project.

Pronto quando: a regra estiver escrita e você a tiver aplicado a uma segunda tarefa sem repensar tudo do zero. Essa reutilização é a prova de que você aprendeu o padrão, e não só o projeto.

How to use this track Como usar esta trilha

Rules that keep 15 minutes honest Regras que mantêm os 15 minutos honestos

One session per day, maximum

No máximo uma sessão por dia

Several sessions need a night to pass so the machine can run without you. Doing four in one sitting skips the only part that teaches anything.

Várias sessões precisam que uma noite passe para a máquina rodar sem você. Fazer quatro de uma vez pula justamente a parte que ensina.

Stop at 15 minutes even mid-task

Pare aos 15 minutos, mesmo no meio

Write where you stopped in LOOP-LOG.md. Picking up a written handoff is itself the skill — it is exactly what you are teaching the loop to do.

Escreva onde parou no LOOP-LOG.md. Retomar a partir de uma anotação é a habilidade em si — é exatamente o que você está ensinando o loop a fazer.

Never skip a read-only block

Nunca pule um bloco de leitura

The cost of Blocks 1 and 2 is boredom. The cost of skipping them is an autonomous system you disable in May and never turn back on.

O custo dos Blocos 1 e 2 é tédio. O custo de pulá-los é um sistema autônomo que você desliga em maio e nunca mais religa.

Add no new tools

Não adicione ferramentas novas

Twelve sessions, zero installs. If a session tempts you into a new framework, that is the old habit — collecting capability instead of running a loop.

Doze sessões, zero instalações. Se uma sessão te tentar a um framework novo, é o hábito antigo — colecionar capacidade em vez de rodar um loop.

The whole track in one sentence A trilha inteira em uma frase

Trigger starts it, state remembers it, the gate stops it, the signal calls you — and your rating is what makes tomorrow's run better than today's.

O trigger começa, o estado lembra, o gate para, o sinal te chama — e a sua avaliação é o que faz a execução de amanhã ser melhor que a de hoje.
