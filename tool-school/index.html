Built For Beginners

A better website for learning AI tools without getting lost

This project is now a starter school for the tools you want to get good at: Codex, Claude Code, and OpenClaw first, with Notion and Warp as support layers. It is built as a readable, local-first website so you can learn one tool at a time without drowning in docs.

This is also part of the proof: this was built on a first serious hands-on pass. The point is not “look how advanced this is.” The point is someone new can read, follow, and build useful results too.

The idea is simple: read the beginner guide, follow the learning path, and use the morning checklist until the workflows start to feel natural.

Um site melhor para aprender ferramentas de IA sem se perder

Este projeto agora virou uma escola inicial para as ferramentas que você quer dominar: primeiro Codex, Claude Code e OpenClaw, com Notion e Warp como camadas de apoio. Ele foi feito como um site local, legível e prático para você aprender uma ferramenta por vez sem se afogar em documentação.

Isso também serve como prova: tudo isso foi construído em uma primeira passada séria e prática. A ideia não é “olha como isso é avançado”. A ideia é mostrar que alguém começando agora consegue ler, seguir e produzir resultados úteis também.

A lógica é simples: leia o guia de iniciante, siga a trilha de aprendizado e use o checklist da manhã até os fluxos começarem a parecer naturais.

Codex Vs Claude Code Codex Vs Claude Code

Use the right coding tool for the right job Use a ferramenta de código certa para o trabalho certo

Codex

Best when you want a visible result fast: edit local files, build one page, debug one issue, or ask for a safer implementation with verification.

Melhor quando você quer um resultado visível rápido: editar arquivos locais, construir uma página, depurar um problema ou pedir uma implementação mais segura com verificação.

Start prompt: “Read this folder, explain the current structure, then build one small beginner-friendly page and verify it.”

Prompt inicial: “Leia esta pasta, explique a estrutura atual e depois construa uma página pequena para iniciantes e verifique.”

Claude Code

Best when the student needs terminal-first repo work: understand a codebase, plan one change, run through a workflow, or make one bounded implementation in a real repository.

Melhor quando o aluno precisa de trabalho em repositório via terminal: entender a base de código, planejar uma mudança, seguir um workflow ou fazer uma implementação limitada em um repositório real.

Start prompt: “Explain this repo in plain English, show me the key files, then help me make one safe change and verify it.”

Prompt inicial: “Explique este repositório em inglês simples, mostre os arquivos principais e depois me ajude a fazer uma mudança segura e verificar.”

Learning Paths Trilhas de Aprendizado

Pick the path that matches what you actually want to do Escolha a trilha que combina com o que você realmente quer fazer

Beginners need a sequence, not a random feature dump.

Iniciantes precisam de uma sequência, não de um despejo aleatório de recursos.

Codex Builder Path

  • Start with the First Build page so you get one visible result without overthinking the stack.
  • Read the Codex guide next and practice one prompt with goal, scope, constraints, and verification.
  • Use the AI Teacher to refine your prompt before asking Codex to build or edit anything.
  • Only after the first result works, use Notion to organize what you learned and what comes next.

Trilha do Construtor com Codex

  • Comece pela página de Primeira Construção para obter um resultado visível sem pensar demais na stack.
  • Leia o guia do Codex em seguida e pratique um prompt com objetivo, escopo, restrições e verificação.
  • Use o AI Teacher para refinar seu prompt antes de pedir para o Codex construir ou editar qualquer coisa.
  • Só depois que o primeiro resultado funcionar, use o Notion para organizar o que aprendeu e o que vem a seguir.

Claude Builder Path

  • Start with the First Build page and decide what one safe repo task looks like before opening a real codebase.
  • Read the Claude Code guide and learn the step order: understand repo, ask one bounded question, make one change, verify.
  • Use the AI Teacher to rewrite vague requests into terminal-ready instructions.
  • Use Warp only as support to make terminal work cleaner and easier to repeat.

Trilha do Construtor com Claude

  • Comece pela página de Primeira Construção e decida como é uma tarefa segura de repositório antes de abrir uma base de código real.
  • Leia o guia do Claude Code e aprenda a ordem: entender o repositório, fazer uma pergunta limitada, mudar uma coisa, verificar.
  • Use o AI Teacher para reescrever pedidos vagos em instruções prontas para terminal.
  • Use o Warp apenas como apoio para deixar o trabalho de terminal mais limpo e repetível.

OpenClaw Operator Path

  • Start with the OpenClaw guide and define one assistant job that stays narrow, private, and reviewable.
  • Use the AI Teacher to decide which channels should not be automated yet.
  • Use Codex or Claude Code only when the assistant flow also needs code, local files, or repository work.
  • Use Notion and Warp later to document decisions and operational routines.

Trilha do Operador com OpenClaw

  • Comece pelo guia do OpenClaw e defina uma tarefa do assistente que continue limitada, privada e revisável.
  • Use o AI Teacher para decidir quais canais ainda não devem ser automatizados.
  • Use Codex ou Claude Code apenas quando o fluxo do assistente também precisar de código, arquivos locais ou trabalho em repositório.
  • Use Notion e Warp depois para documentar decisões e rotinas operacionais.
