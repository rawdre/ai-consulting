Step 2 · Turn On The AI Teacher Passo 2 · Ligue o AI Teacher

Put your OpenRouter key in the right place Coloque sua chave do OpenRouter no lugar certo

1

Create a free OpenRouter account

Crie uma conta gratuita no OpenRouter

Go to openrouter.ai and sign up. It's free to start.

Vá em openrouter.ai e cadastre-se. É grátis para começar.

2

Create your key

Crie sua chave

Open openrouter.ai/keys → Create Key → copy the long code it gives you.

Abra openrouter.ai/keys → Create Key → copie o código longo que aparece.

3

Open Settings on this site

Abra as Configurações neste site

Find the ⚙ Settings button (the AI Teacher panel). This is the "right place" — not inside Codex, but here, where the Teacher lives.

Encontre o botão ⚙ Configurações (o painel do AI Teacher). Este é o "lugar certo" — não dentro do Codex, mas aqui, onde o Teacher mora.

4

Paste the key and keep the free model

Cole a chave e mantenha o modelo gratuito

Leave provider on OpenRouter, paste your key in the API key field, and leave the free model in place. Save.

Deixe o provedor em OpenRouter, cole sua chave no campo API key e mantenha o modelo gratuito. Salve.

5

Test it — ask a question and press Enter

Teste — faça uma pergunta e aperte Enter

Type "what is my first step to build a website?" and press Enter. If it answers, you're live. If it says the model isn't available, open Settings and paste a working one from openrouter.ai free models. Your key stays only in your browser.

Digite "qual é meu primeiro passo para construir um site?" e aperte Enter. Se responder, está no ar. Se disser que o modelo não está disponível, abra as Configurações e cole um que funcione de modelos gratuitos do openrouter.ai. Sua chave fica só no seu navegador.

Step 3 · Build The Page Passo 3 · Construa a Página

Prompt your builder so the result is actually good Oriente seu construtor para o resultado ficar realmente bom

1

Decide the one page

Decida a página única

Keep it small: a one-page site for one thing — your service, an event, a portfolio. One page you can finish today.

Mantenha pequeno: um site de uma página para uma coisa — seu serviço, um evento, um portfólio. Uma página que dá para terminar hoje.

2

Give the builder a clear, bounded prompt

Dê ao construtor um prompt claro e limitado

Goal, scope, constraints, and "verify it." Vague in, vague out — from the How AI Works guide.

Objetivo, escopo, restrições e "verifique". Vago na entrada, vago na saída — do guia Como a IA Funciona.

3

Review once, improve once, then stop

Revise uma vez, melhore uma vez, e pare

One pass for clarity, one for looks. First builds should finish, not sprawl.

Uma passada por clareza, uma por beleza. Primeiras construções devem terminar, não inchar.

4

Open the file in your browser

Abra o arquivo no navegador

Double-click the index.html the builder made. If it opens and looks right, you have a working website on your computer. Next: put it online.

Dê dois cliques no index.html que o construtor criou. Se abrir e estiver certo, você tem um site funcionando no seu computador. Agora: coloque online.

Copy-paste starter prompt (works for Codex or Claude) Prompt inicial para copiar (funciona no Codex ou Claude) 
Build one simple, beginner-friendly website as a single index.html file.
Goal: a clean one-page site for [WHAT IT'S FOR].
Include: a headline, a short intro paragraph, three feature boxes, and one
call-to-action button. Use only plain HTML and CSS in one file, no frameworks.
Keep the colors tasteful and the layout mobile-friendly.
When done, tell me how to open it and what to change if I want a different color.
Construa um site simples e amigável para iniciantes como um único arquivo index.html.
Objetivo: um site limpo de uma página para [PARA QUE SERVE].
Inclua: um título, um parágrafo curto de introdução, três caixas de recursos e um
botão de ação. Use só HTML e CSS puros em um arquivo, sem frameworks.
Mantenha as cores agradáveis e o layout adaptado para celular.
Ao terminar, me diga como abrir e o que mudar se eu quiser outra cor.
Step 4 · Put It Online Passo 4 · Coloque Online

Three ways to make it live — pick one Três formas de deixar no ar — escolha uma

GitHub Pages — easiest & free (recommended)

GitHub Pages — mais fácil e grátis (recomendado)

  • On github.com, click New repository, name it, make it Public, Create.
  • Click Add file → Upload files, drag in your index.html, Commit.
  • Go to Settings → Pages, set Source to your main branch, Save.
  • Wait a minute — your live link appears: yourname.github.io/repo.
  • No github.com, clique New repository, dê um nome, deixe Public, Create.
  • Clique Add file → Upload files, arraste seu index.html, Commit.
  • Vá em Settings → Pages, defina Source na branch main, Save.
  • Espere um minuto — seu link ao vivo aparece: seunome.github.io/repo.

Vercel — fast, great previews

Vercel — rápido, ótimos previews

  • Sign in at vercel.com with GitHub.
  • Click Add New → Project, import your GitHub repo.
  • Leave the defaults, click Deploy.
  • You get a live .vercel.app link in seconds.
  • Entre em vercel.com com o GitHub.
  • Clique Add New → Project, importe seu repositório do GitHub.
  • Deixe os padrões, clique Deploy.
  • Você recebe um link .vercel.app ao vivo em segundos.

Render — good for growing later

Render — bom para crescer depois

  • Sign in at render.com with GitHub.
  • Click New → Static Site, connect your repo.
  • Leave build empty, publish directory = the folder with index.html, Create.
  • You get a live .onrender.com link.
  • Entre em render.com com o GitHub.
  • Clique New → Static Site, conecte seu repositório.
  • Deixe o build vazio, publish directory = a pasta com o index.html, Create.
  • Você recebe um link .onrender.com ao vivo.
